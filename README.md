# ShopEase – Fashion E-commerce Website

ShopEase is a fashion e-commerce web application built using HTML, CSS, JavaScript, Java Spring Boot, and MySQL. It allows users to view products, add items to a shopping cart, and manage products.

## Features
- Display fashion products
- Add products to the shopping cart
- Add new products
- Delete products
- Store product details using MySQL
- REST API integration between frontend and backend

## Technologies Used
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Java, Spring Boot
- **Database:** MySQL
- **Tools:** VS Code, Git, GitHub, Maven

## Project Structure
- `index.html` – Website structure
- `style.css` – Website styling
- `script.js` – Frontend logic and API calls
- `backend/` – Spring Boot application and database integration

## Prerequisites
- Java 21
- MySQL
- Maven (or the included Maven Wrapper)

## Setup
1. Clone this repository.
2. Create a MySQL database named `shopease`.
3. Configure your database username and password locally.
4. Set the `DB_PASSWORD` environment variable to your local MySQL password.
5. Run the backend from the `backend` folder using the Maven Wrapper.
6. Open `index.html` in a browser.

- Connecting Java applications to MySQL
